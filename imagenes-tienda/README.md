# Imágenes de Blue Fragancias

Copia aquí las imágenes que quieras utilizar o tomar como referencia para la tienda.

| Carpeta | Qué guardar |
|---|---|
| `logos` | Logo principal, versiones con fondo transparente e iconos de la marca |
| `perfumes` | Fotografías de frascos, cajas, decants y muestras |
| `banners` | Imágenes para la portada, promociones y fondos |
| `referencias` | Ejemplos de diseños, colores o estilos que te gusten |

Para los perfumes, puedes crear una subcarpeta por producto. Usa nombres que
permitan reconocer la marca, el perfume y la vista, por ejemplo:
`marca-nombre-perfume-100ml-frente.jpg` y `marca-nombre-perfume-100ml-caja.jpg`.
Si todavía no puedes organizarlas, déjalas en la carpeta correspondiente y luego
las ordenamos.

Conserva los originales con la mejor calidad disponible. Puedes aportar JPG,
PNG, WebP o SVG; para el logo, PNG transparente o SVG si los tienes.

Cuando hayas copiado archivos, indica en el chat que están listos para revisarlos.
Guardar imágenes aquí no las incorpora automáticamente a la página: después
seleccionaremos las adecuadas, prepararemos su tamaño y las conectaremos al sitio.

También podrás seleccionar los archivos desde el panel `/admin` para cambiar
el logo o la foto de portada de un producto, sin editar código, cuando se complete
su preparación inicial. [Guía del panel](../documentacion/PANEL-ADMINISTRACION.md).
Las referencias generadas para el diseño están en `frontend/public/referencias`.
